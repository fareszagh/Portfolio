# Fares Zaghdoudi — Portfolio

A multilingual (English / Deutsch / Français) portfolio built with React and Vite.

## Run it

```bash
npm install
npm run dev       # local dev server at http://localhost:5173
npm run build     # production build into dist/
npm run preview   # serve the production build locally
```

## Edit content

- `src/config.js` — email, LinkedIn, GitHub, and the Gastronome.tn repo/live links. Empty links are hidden.
- `src/content.js` — all text on the site, one block per language.
- `public/cv/` — the downloadable CV for each language.

## Deploy

`dist/` is a static site: drag it onto Netlify, or deploy the repo on Vercel / GitHub Pages.
